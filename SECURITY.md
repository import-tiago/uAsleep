# Security policy

## Supported versions

Security fixes are applied to the latest 2.x release.

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No |

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues, discussions, or pull
requests.

Send a private report to `tiagodepaulasilva@gmail.com` with:

- the affected version and platform;
- clear reproduction steps or a proof of concept;
- the potential impact;
- any suggested mitigation.

Avoid including real credentials or personal data. Please allow the maintainer
reasonable time to investigate and release a fix before public disclosure.
